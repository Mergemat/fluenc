# Curriculum sources

- `character-keywords.reviewed.json`: one selected pronunciation and English mnemonic keyword for every curriculum character. Each choice records an exact CC-CEDICT reading and sense, plus an editorial note. These are AI-assisted editorial choices, checked against the dictionary; they are not a human linguist certification or a reproduction of Mandarin Blueprint's course.
- `character-dictionary.source.json`: filtered CC-CEDICT snapshot covering the curriculum. Published by [MDBG / CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict), downloaded from the URL recorded in the file. The upstream publication timestamp and complete-download SHA-256 are preserved. Changes: filtering to curriculum characters and converting to JSON; dictionary readings and senses are retained verbatim.
- `word-corrections.reviewed.json`: selected corrections to the upstream word list, with dictionary evidence. A character's lesson reading does not override readings in words.
- `reviewed-compositions.json`: reviewed mnemonic component choices; see [decomposition audit](../../docs/research/character-decompositions.md).
- `curriculum.generated.json` and `hanzi-index.generated.json`: generated by `bun run data:sync`. Character keywords are never inferred from dictionary order. Generation fails on missing reviews, duplicate reviews, or a selected reading/sense absent from the pinned dictionary.
